Architecting Scalable REST APIs for Campus Portals using Node.js and MySQL

Published by Snehal Deshmukh on 12 October 2026 • Reading Time: 6 minutes

Introduction and Architectural Problem Statement

Modern campus portals manage fluctuating traffic surges during semester registration and placement season. Traditional monolithic architectures often fail under sudden concurrent loads due to database connection exhaustion and blocking I/O operations. In this technical writeup, we analyze how a decoupled 3-tier architecture with connection pooling resolves these bottlenecks.

Key Architectural Principles

  1. Connection Pooling: Utilizing mysql2/promise connection pools prevents the overhead of creating and tearing down TCP handshakes on every incoming HTTP request.
  2. Parameterized Queries: Protecting campus databases from SQL injection vulnerabilities by enforcing prepared statements across all student CRUD operations.
  3. Stateless Authentication: Employing JSON Web Tokens (JWT) to verify student identities across distributed endpoints without server-side memory session bloat.

Demystifying Git Branching Strategies for College Hackathon Teams

Published by Rohit Sandip Patil on 28 September 2026 • Reading Time: 4 minutes

The Chaos of Rapid Hackathon Collaboration

During 36-hour hackathons like Smart India Hackathon, teams frequently stumble into merge conflicts, overwritten code, and broken master branches. Adopting a structured, lightweight Git strategy transforms team productivity.

We recommend a three-branch workflow:

  • main: Production-ready code; demo deployable at any moment.
  • dev: Integration branch where team members merge verified features.
  • feature/*: Isolated branches for individual sub-modules (e.g., feature/login-ui, feature/api-routes).
